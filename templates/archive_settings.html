One-time Docker setup

Use the provided docker-compose.drive.yml.example to bind an existing folder on your other hard drive to /backup-drive. Set ARCHIVE_SETTINGS_ROOT=/backup-drive and rebuild with that override. Drive access must be granted to Docker Desktop. Do not use a folder on the same physical disk just to change the drive letter.

Existing backup jobs keep their original destination identity and folder. Settings changes cannot redirect removal to a different location. Always test using disposable videos first.
